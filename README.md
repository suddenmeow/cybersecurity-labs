# Cybersecurity Labs

Hands-on cybersecurity lab portfolio documenting practical exercises, technical investigations, detection engineering, and lessons learned.

## Lab reports

| Platform | Lab | Skills demonstrated | Report |
|---|---|---|---|
| TryHackMe | **Fools Mate** | Browser developer tools, JavaScript debugging, web application logic | [Read report](tryhackme/fools-mate/README.md) |
| TryHackMe | **Summit** | SOC investigation, malware sandbox triage, IOC analysis, firewall and DNS controls, Sigma-style detections, Pyramid of Pain | [Read report](tryhackme/summit/README.md) |

The reports are written as portfolio case studies describing the investigation, evidence, controls, findings, and practical limitations. All work was performed in authorized training environments.
